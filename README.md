# Bachelor’s thesis: zeros of Sobolev orthogonal polynomials

Source material for my BSc thesis at Universidad Politécnica de Madrid, *Zeros of Sobolev Orthogonal Polynomials: Visualization and Analysis*. The work combines mathematical analysis with Maple computations and visualisations of polynomial zeros.

## Repository map

- `latex/tfg_latex_etsiinf-2023.02.20/tfg_etsiinf_plantilla.tex` — main LaTeX document for the thesis. Its `secciones/` directory contains the chapters and bibliography; `include/` contains figures and title-page assets.
- `latex/presentacion.tex` — presentation source, with sections in `latex/`.
- `maple/` — Maple worksheets and scripts used for the numerical investigations.
- Other `.tex` files in `latex/` — working notes and drafts.

The compiled PDFs and local copies of reference papers are omitted. Build outputs can be regenerated from the LaTeX sources with a suitable TeX installation; this repository has no verified one-command build. Figures used by the thesis remain in `include/`.
